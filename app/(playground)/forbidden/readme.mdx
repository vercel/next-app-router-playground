# Forbidden

`forbidden.js` is a file convention that lets you define fallback UI for a route segment when the `forbidden()` function is thrown.

Use it when a user is signed in but does not have access to a route.

### Demo

- This route renders the fallback UI from `forbidden.tsx`.
- In an app, Next.js renders this file when `forbidden()` is thrown.
