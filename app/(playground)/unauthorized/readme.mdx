# Unauthorized

`unauthorized.js` is a file convention that lets you define fallback UI for a route segment when the `unauthorized()` function is thrown.

Use it when a user needs to sign in before they can access a route.

### Demo

- This route renders the fallback UI from `unauthorized.tsx`.
- In an app, Next.js renders this file when `unauthorized()` is thrown.
