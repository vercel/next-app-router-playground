# !!col

With Cache Components, `unstable_paramMatching` controls how a route handles
parameter values not returned by `generateStaticParams()`.

- `not-found` returns 404.
- `blocking` waits for the page to be generated.
- `fallback` shows a Suspense fallback while generating the page.
- `dynamic` resolves the parameter per request instead of prerendering it.

# !!col

```tsx app/param-matching/fallback/[id]/page.tsx
import type { ParamMatching } from 'next';

// !mark
export const unstable_paramMatching = {
  id: 'fallback',
} satisfies ParamMatching<'id'>;

export function generateStaticParams() {
  return [{ id: '1' }];
}
```
