- `unstable_prefetch()` excludes subsequent content from the shared App Shell. `<Link prefetch={true}>` can include it in a per-link prefetch.
- **Shorts** uses a default `<Link>`, so its session-driven recommendations wait for navigation.

```tsx app/prefetch-stages/await-prefetch/page.tsx
async function RecommendationsAfterPrefetch() {
  const sessionId = (await cookies()).get('session-id')?.value ?? 'guest';
  // !mark
  await prefetch();
  return getSessionRecommendations('2', sessionId);
}
```

The stage APIs run outside cached functions. Work below each gate can still use `use cache`:

```tsx app/prefetch-stages/_components/product.tsx
async function getRecommendationsCached(id) {
  // !mark
  'use cache';
  return db.product.findMany({ limit: 3 });
}
```

### Demo

- Click **Top** to see prefetched product details render immediately while cached recommendations stream in after navigation.
- Click **Shorts** to see its product details in the App Shell while cached recommendations stream in after navigation.
- Each data function includes an artificial delay to make the stages visible. Prefetching only runs in production.

### Notes

- This demo uses the experimental `unstable_navigation()` and `unstable_prefetch()` APIs.
