- `unstable_prefetch()` excludes subsequent content from the App Shell.
- **Shorts** uses a default `<Link>`, so its cached product details wait for navigation.


Both stage APIs are called outside the cached functions. The data remains cacheable:

```tsx app/prefetch-stages/_components/product.tsx
async function getRecommendationsCached(id) {
  // !mark
  'use cache';
  return db.product.findMany({ limit: 3 });
}
```

### Demo

- Click **Top** to compare prefetched product details with recommendations that begin at navigation.
- Click **Shorts** to see product details stream into its prefetched App Shell.
- Artificial delays make each stage visible. Prefetching only runs in production.

### Notes

- This demo uses the experimental `unstable_prefetch()` and `unstable_navigation()` APIs.
