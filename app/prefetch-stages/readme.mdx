```tsx app/prefetch-stages/product/page.tsx
async function PrefetchedRecommendations() {
  const sessionId = (await cookies()).get('session-id')?.value;
  // !mark
  await prefetch();
  return getSessionRecommendations('1', sessionId ?? 'guest');
}

async function NavigationOnlyProducts() {
  // !mark
  await navigation();
  return getMoreProducts('1');
}
```

The stage APIs run outside cached functions. Work below each gate can still use `use cache`:

```tsx app/prefetch-stages/_components/product.tsx
async function getMoreProducts(id) {
  // !mark
  'use cache';
  return db.product.findMany({ limit: 3 });
}
```

### Demo

- The product details are part of the shared App Shell and are always prefetched.
- `<Link prefetch={true}>` also includes the private cached recommendations after `unstable_prefetch()`.
- Click the product to see those two sections immediately while the section after `unstable_navigation()` streams in.
- Each data function includes an artificial delay to make the stages visible. Prefetching only runs in production.

### Notes

- This demo uses the experimental `unstable_prefetch()` and `unstable_navigation()` APIs.
