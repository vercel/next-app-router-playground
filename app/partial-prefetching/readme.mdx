# !!col

- `<Link>` prefetches the App Shell only.
- `<Link prefetch={true}>` also includes any `'use cache'` boundaries the route can resolve from the URL.
- A route that exports `prefetch = 'allow-runtime'` lets that same `<Link prefetch={true}>` include `'use cache: private'` boundaries that read cookies or headers.

### Demo

- All three tiles open the same page, which renders three Suspense boundaries: `<Hero>` (`'use cache'`), `<Stock>` (uncached), `<Recommendations>` (`'use cache: private'`).
- **Live**: bare `<Link>`. Only the App Shell is prefetched. All three sections stream in on click.
- **Details**: `<Link prefetch={true}>`. `<Hero>` is included in the prefetch and lands immediately. `<Stock>` and `<Recommendations>` still stream.
- **For you**: `<Link prefetch={true}>` to a route that exports `prefetch = 'allow-runtime'`. `<Hero>` and `<Recommendations>` are in the prefetch. Only `<Stock>` streams.
- A 1.5 second artificial delay is added to the cached functions, 3 seconds to the private cache, to make the difference visible.

### Notes

- This demo uses the `use cache` directive.
