# !!col

- `<Link>` prefetches the App Shell only.
- `<Link prefetch={true}>` adds static cached content. Runtime-dependent content still streams.
- `prefetch = 'allow-runtime'` on the destination prefetches a runtime prerender (cookies, headers, search params resolved ahead of the click).

### Demo

Each destination renders the same four sections: **static**, `'use cache'`, `'use cache: private'`, and uncached (`connection()`). The hub passes a distinct `?id` so the `'use cache'` key depends on a runtime value — otherwise the difference between `<Link>` and `<Link prefetch={true}>` is invisible.

Open DevTools → Network, filter `_rsc=`, and watch what arrives in the prefetch vs. what streams after the click.
