# !!col

- `<Link>` prefetches the App Shell only.
- `<Link prefetch={true}>` also includes any `'use cache'` boundaries the route can resolve from the URL.
- A route that exports `prefetch = 'allow-runtime'` lets that same `<Link prefetch={true}>` include `'use cache: private'` boundaries that read cookies or headers.

### Demo

- Each tile opens a different route whose body uses the boundary type that its link can prefetch.
- **Live**: bare `<Link>`. The body is uncached, so only the App Shell is prefetched and the card streams in on click.
- **Details**: `<Link prefetch={true}>`. The body is `'use cache'` keyed by id, so the rendered card is included in the prefetch and lands immediately on click.
- **For you**: `<Link prefetch={true}>` to a route that exports `prefetch = 'allow-runtime'`. The body is `'use cache: private'` and reads the session cookie, so the personalised card is included in the prefetch.
- A 1.5 second artificial delay is added to the cached functions, 3 seconds to the private cache, to make the difference visible.

### Notes

- This demo uses the `use cache` directive. `use cache: private` is currently experimental.
